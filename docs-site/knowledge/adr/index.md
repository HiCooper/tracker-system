# 架构决策记录 (ADR)

> 记录 Tracker 埋点系统的重要技术决策及其背景和权衡。

## ADR-001: 独立部署 Tracker 服务

**状态**: 已采纳

**背景**: 早期设计中埋点功能耦合在 AB 实验服务内部。

**决策**: 将埋点系统拆分为独立的 Tracker Server，与 AB Server 通过 user_id 在 ClickHouse 查询层关联。

**理由**:
- 埋点流量远大于实验分流流量，耦合会相互影响
- 独立部署可单独扩缩容
- 故障隔离，埋点写入失败不影响实验分流

**权衡**: 需要维护额外的服务；跨系统关联依赖查询层 JOIN。
