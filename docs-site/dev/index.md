# 技术架构概览

Tracker System 是 GateFlow 埋点分析数据采集平台，独立于 AB 实验系统部署，负责全站用户行为数据的采集、处理、存储和分析。

## 系统定位

- **独立部署**: 与 AB 实验服务解耦，可独立运维和扩展
- **全面采集**: 覆盖曝光、点击、停留时长、滚动深度、路径等维度
- **高性能**: 支持高并发批量写入，客户端离线队列保障数据不丢失
- **可靠性**: 熔断保护、DLQ 死信队列、Redis 去重

## 与 AB 系统的关系

```
┌──────────────────────────────────────────────┐
│                 客户端 SDK                     │
│  ┌────────────────┐  ┌────────────────────┐  │
│  │  GateFlow SDK  │  │   Tracker SDK      │  │
│  │  实验分流      │  │   行为数据采集      │  │
│  └───────┬────────┘  └─────────┬──────────┘  │
└──────────┼──────────────────────┼─────────────┘
           │                      │
           ▼                      ▼
┌──────────────────┐  ┌────────────────────────┐
│  AB Server       │  │  Tracker Server        │
│  (实验管理/分流)  │  │  (事件接收/存储/聚合)   │
└──────────────────┘  └────────────────────────┘
           │                      │
           └──────────┬───────────┘
                      │  (通过 user_id 关联)
                      ▼
              ┌──────────────┐
              │  ClickHouse  │
              │  (共享存储)   │
              └──────────────┘
```
